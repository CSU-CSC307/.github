# CSC 307 — Introduction to Software Engineering

Course repositories for **CSC 307: Introduction to Software Engineering** at
California Polytechnic State University, San Luis Obispo.

This organization contains software projects, programming assignments, and
team repositories from multiple offerings of the course.

## Winter 2026

The Winter 2026 offering used **TaigaStudio**, a Java application, as the
software system for applying software engineering concepts and practices.

The repositories document the progression of the course through the original
TaigaStudio application, refactoring work, TaigaStudio 3.0, and the final
team project.
